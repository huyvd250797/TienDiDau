# TienDiDau V1.1.2 — Yarn Netlify Fix

## Thay đổi

- Chuyển Netlify dependency installer từ npm sang Yarn Classic 1.22.22.
- Thêm `packageManager: yarn@1.22.22` để Netlify nhận diện Yarn ngay cả khi repository không có lockfile.
- Thêm `NETLIFY_USE_YARN=true` làm cơ chế ép package manager ở Netlify.
- Xóa `.npmrc` và loại bỏ các lockfile npm/pnpm có thể khiến Netlify quay lại npm.
- Thêm Yarn resolution ghim `@firebase/webchannel-wrapper` ở 1.0.6.
- Đồng bộ GitHub Actions sang Yarn.
- Nâng nhãn ứng dụng và Health API lên V1.1.2.

## Dấu hiệu deploy đúng

Netlify phải chạy `yarn install`, sau đó `yarn build`. Nếu log vẫn hiện `Installing npm packages`, repository hoặc cấu hình Netlify vẫn còn file/biến cũ và cần deploy lại bằng tùy chọn **Clear cache and deploy site**.
